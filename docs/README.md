# Turm documentation

- [Project actions](project-actions.md): how the project bar detects a project, the tool selector and option dropdowns, the "..." menu, the Project Bar settings tab and sub-shell mode.
- [Turm.json](turm-json.md): the per-project file that adds, hides and replaces actions and controls the bar for that project.
- [Shortcuts](shortcuts.md): `@` directory, `!` command and `#` file shortcuts, how they expand, and where to manage them.
- [SSH](ssh.md): the `>` quick route, saved hosts and keys, passwords, and the remote shell integration that keeps blocks working over SSH.
- [Remote Access](remote-access.md): serving the Mac's shells to the iOS app, pairing by QR code or code, connecting over Tailscale, revoking devices and the security model.
- [iCloud sync](icloud-sync.md): what syncs between your Mac and iPhone, how it is protected, Delete iCloud Data and storing an SSH key in Turm.
- [iOS](ios.md): the iPhone and iPad app, with its sidebar, Mac shells, direct SSH and the keyboard bar.
